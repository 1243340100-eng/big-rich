# 资本之城 · CAPITAL CITY

根据《3D多人经济策略大富翁_总体游戏设计_GDD.md》开发的第一版可运行 MVP。

React 19 + TypeScript + React Three Fiber / Three.js + Node.js + Socket.IO。所有资金、骰子、归属、市场与交易由服务端校验与计算。金额为虚拟游戏货币。

## 快速开始

已经安装依赖并生成生产构建，Windows 可双击项目内的 **启动游戏.cmd**。

或在本目录执行：

```powershell
npm start
```

访问 **http://localhost:3001**。在首页点「开始练习对局」，即可与三位机器人开始一局。

首次复制源码到另一台电脑（需 Node.js 22.12+ 或 24）：

```powershell
npm ci
npm run build
npm start
```

开发模式：`npm run dev`，前端 http://localhost:5173，后端 3001。验证：`npm test`。停止服务器：在其终端按 Ctrl+C。

### 进行中的房间：关闭申请、身份接替与观战

首页会显示正在进行的联机房间。可以直接进入只读观战，也可以选择房内一名玩家（包含 AI）申请接替，或申请关闭房间。

关闭和接替均由服务端计时 **10 秒**，向房内真人玩家弹窗；任何一人反对即取消。同意不提前执行，10 秒内无人反对（包括完全无人回应）才执行。玩家关闭弹窗或按 Escape 也视为反对。申请人可撤回，申请人掉线会自动取消；同一房间同一时间只处理一个申请。观众不参与表决。

接替保留原角色名字、职业、资产、位置及对局进度，AI 角色转为真人控制。原玩家返回首页、旧重连凭证失效，新玩家获得独立凭证。观战不占玩家席位，可看棋盘、公开资产和公共聊天；不会收到私聊、私人交易或内幕信息，也不能发送游戏操作。观战刷新后会自动尝试恢复。房间关闭时玩家和观众都会返回首页。

### 外网访问与首页加载（部署）

cpolar 请转发生产服务的 **3001** 端口。`npm run build` 会生成 Brotli/gzip 静态资源；服务端按浏览器支持自动选择压缩版本。带哈希的资源缓存一年，HTML 每次校验更新。首页表单先显示，3D 城市场景随后加载，角色衣橱在打开时加载。

更新服务端代码后，在原游戏终端按 Ctrl+C，再双击 `启动游戏.cmd`，压缩和缓存配置才会生效。仅重复双击启动脚本会复用已有服务，不会重启。cpolar 无需重新配置。

## 与朋友联机

1. 一台电脑运行服务器，打开游戏后「创建好友房间」。
2. 同一局域网的朋友通过 `http://服务器电脑的局域网IP:3001` 打开；开发模式使用 5173。
3. 输入房间码加入，房主选择规则、添加机器人、开始游戏。支持 2–8 个席位。
4. `localhost` 只指向当前设备；跨互联网需要另外部署常驻 Node 服务、域名、HTTPS/WSS 与网络访问配置。本次没有部署公网，也没有更改 Windows 防火墙。

每个浏览器标签页是一个独立玩家身份。刷新原标签页可自动重连；另开标签页可用另一身份加入大厅。不要主动点「离开房间」后期待恢复旧身份。

## 规则摘要

- 默认 200 万初始现金、30 轮；可选 150 / 200 / 300 万和 15 / 30 / 50 轮。
- 一轮是所有玩家各行动一次。期末净资产最高获胜。
- 32 格主环、2 条各长 6 步的内街捷径（已验证无入场费）。从 5–7 或 21–23 格起步时，可拐入内街。仅 31→0 发起点工资。
- 购买无主地产；放弃后全员竞拍。首价市值 50%，最低加价 1 万。首拍 25 秒，每次有效出价重设为 15 秒，全部其他玩家退出则提前结算。最高出价资金预留。
- 地产升级 Lv.0–3，自己回合完成落地后操作。租金随等级和经济周期变化。持有且未抵押的地产在每个个人回合开始获得经营收益：基础租金 × 地块原型系数 × 20% × 等级系数（Lv.0/1/2/3 = 1 / 1.75 / 2.9 / 4.8）× 全局周期 × 街区景气 × 事件风口，扣 10% 所得税；抵押期间暂停。升级会逐级缩短含升级成本的回本期，Lv.3 经营收益为 Lv.0 的 4.8 倍。租金公式保持不变，P1/P2 的街区性格与事件热点先只作用于经营收益。
- 地产抵押取得估值 60%，抵押期间停租。赎回为本金 + 5% 手续费。银行回购价为估值 70% 减抵押本金。
- 六支股票支持买卖、成本、浮盈亏、简化走势和每五轮股息。手续费通常 1%；大单有双向滑点和价格冲击；盈利卖出征收 10% 资本利得税。
- 贷款额度依资产和债务，评级 AAA–D 动态计算。每次个人回合计息，非现实年化利率。存款每个人回合收益 1%，抵押利率为央行基准 + 2%。
- 工资、租金和地产经营收益所得税 10%；每回合地产税为市值 0.8%；地产超过 500 万部分另收 1%；每级建筑维护 0.6 万；税务格征净资产 2.5%，最低 5 万。
- 全球事件间隔 2 / 3 / 4 轮。经济阶段、利率、房产指数和行业股价共同变化。每次事件保留 7 类底层分类，但显示为具体新闻标题（每类 3 条叙事，如“A、B 两国开战，全球运输链中断”），同一轮的内幕和结算使用同一条叙事。事件发生时所有玩家会收到顶部横幅播报（分类、标题、描述、周期、房产指数和当前风口），横幅保持显示，直到玩家点击右上角关闭。
- 2 / 16 / 27 号城市事件格各有 6 条独立事件池：市政消息偏政策、城市公园偏文旅、市场消息偏股市；普通 60% / 少见 30% / 稀有 10%。落点会播放抽卡翻牌动画，现金结果继续按 10% 所得税结算，股市消息只影响报价并写入“城市消息”。
- 每个个人回合开始时显示纸质结算账单（利息、地产税、维护、经营收入、上次结算后的过路租金收入/支出、存款利息、净变化），正账单配 24 张钞票雨和合成金币音效，负账单改为红色 `-￥` 符号雨和低沉落账音；账单保持显示，直到玩家点击关闭。音效需在“更多操作 → 反馈设置”中开启，默认静音；减少动态效果会关闭钞票雨。
- 对局结束时播放冠军结算动画：金杯、彩带/金币雨、最终净资产排名和胜利号角；动画只在“进行中 → 已结束”时触发，可手动关闭查看棋盘或返回首页。
- 玩家交易支持双向现金、各一处地产、各一支股票；接受时重新校验，原子成交。可拒绝、撤回、还价，两轮后过期。每人最多五笔未完成提案。
- 其他玩家回合也能操作股票、银行、交易和竞拍。公共聊天与真人私聊可用。
- 现金不足时可筹资；自己回合可重组：清算股票存款、收回地产拍卖、剩余债务减免 80%、永久 D 评级、获得 30 万重启金。重组结束后进入管理阶段，本次未完成的移动作废。
- 星港赌场位于 19 号特殊地块，仅当回合停留时可选进入。固定 20 格牛熊轮盘，25% 崩盘、单转理论期望 0.96；每次停留一次入场，最多 10 转、10 倍，筹码受现金保护线限制。场内禁止其他资产操作，短暂刷新恢复，断线 45 秒或服务重启自动落袋。仅使用游戏虚拟现金。
- 到期租金允许现金暂时为负，视为短期支付缺口；在掷骰或结束回合前必须解决。机器人可临时代管离线玩家：回合开始后满 60 秒且玩家仍离线时触发。

## 项目文件

棋盘周围已加入城市碗：环街、70 栋近景、60 栋中景、42 座坡屋顶、环城水系与桥面。拉远会逐步显现 90 栋远景楼群并扩大取景；默认镜头保持原构图。外围城市跟随早晨／黄昏／深夜变化，夜间有材质亮窗，单独近看建筑时自动隐藏。参数集中在 `src/scene/distantCity.ts` 的 `CITY`，实施记录见 `docs/周边城市群_城市碗实施记录_20261025.md`。

玩家棋子已由汽车替换为 8 款城市伙伴：招财小猫、存钱罐小猪、华尔街之狼、复利小兔、富贵熊猫、金库小熊、算盘小狐、掌柜企鹅。开局前点击“你的城市伙伴”选择，对局中点击顶部角色图标更换；支持旋转查看三维细节。皮肤仅改变外观，所有玩家都会看到房间内的换装结果，刷新重连后保留。棋子按三排站位，保留沿街移动与镜头跟随。

角色模型、总览图和独立 GLB 模型包见 `artifacts/character-skins-20261025/`，实现与验证说明见 `docs/城市伙伴角色皮肤_20261025.md`。

对局中的光影按实际经过时间自动循环：早晨 90 秒 → 黄昏 90 秒 → 深夜 90 秒，每 4 分 30 秒进入下一天。右上角显示当前时段和倒计时；等待操作或切换回合不会重置时间。房间开局时间由服务端保存，刷新、重连和服务重启后继续同一时间进度，对局结束后保留结束时的光影。旧对局首次升级时以最近一回合的开始时间补齐时钟。

城市典藏（`models.html`）仍使用早晨／黄昏／深夜手动按钮，保留所选光影；模型页选择不会覆盖正在进行的对局时间。侧栏新增“效果预览”：可选择城市事件样例播放抽卡翻牌动画、选择全球事件样例播放顶部横幅，或播放胜利结算动画。

## 数据与交付边界

- 对局每约 1.5 秒写入 `data/rooms.json`，重启后自动恢复；非活跃房间保留七天。快照包含玩家重连令牌，应作为私有存档保管，不要分享。
- 纯本地文件快照，未接入 PostgreSQL；适合单进程、朋友局。没有账号系统、跨节点并发、匹配大厅、观战、语音、公网运维或商业化。
- 素材由 Three.js 几何体生成，无外部模型、CDN 或在线字体运行依赖。首次安装依赖需要网络；安装后本机游戏不需要互联网。
- MVP 的金融参数是首轮可玩基线，未经过长期玩家平衡测试。后续企业系统、IPO、担保、联合投资、保险和高级合同见需求文档。
- 浏览器必须支持 WebGL；建议桌面鼠标操作。小屏可滚动到资产面板，并通过「城市概况 / 会客厅」查看玩家与聊天。手机端回合账单和地块详情默认收起，只显示盈亏/余额或必要地块信息，点击可展开全部；城市会客厅收到其他玩家的新消息时，顶部菜单/会客厅按钮会显示未读数字并轻微脉冲，打开会话后清除；对局内「⋯ → 反馈与性能 → 性能模式」可降低渲染分辨率、关闭动态阴影和城市装饰动画，适合手机发热或掉帧时使用。

环境变量：`PORT`（默认 3001）、`DATA_DIR`（默认项目 `data` 目录）。部署时应让前端与 Socket.IO 使用同域。
