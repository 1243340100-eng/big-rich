# 城市会客厅未读提醒

## 行为

- 其他玩家发来公开消息或私聊时，城市会客厅入口显示未读数字。
- 手机端入口在右上角 `⋯` 菜单：按钮出现红色未读角标，菜单里的「城市会客厅 · N」也显示数量。
- 桌面端同时覆盖顶栏会客厅图标、左侧「城市会客厅」按钮和棋盘快捷栏图标。
- 未读数按 **其他人发来的消息** 累计，自己的消息不计入；超过 9 显示 `9+`。
- 打开城市会客厅后立即清零；会话开着时收到新消息不累计，并自动滚动到最新一条。
- 首次进入房间/刷新重连时，以当前最后一条消息为基线，不会把历史消息全部算成未读。
- 提醒同时提供 `aria-label`、`aria-live` 和未读数字，减少动态效果/性能模式下脉冲动画停止。

## 实现

- `src/App.tsx`
  - `unreadChats` 状态和 `chatSeen` 游标
  - 按 `state.chats` 的新增项计数
  - 自动滚动 `chatLogRef`
  - 顶栏、菜单、左侧按钮、快捷栏的数量展示
- `src/mobile-layout.css`
  - `.chat-unread-badge`、`.chat-dock-badge`、脉冲动画
  - `reduce-motion` / `performance-mode` 下取消动画

## 验证

- `npm test`：223 项通过。
- `npm run build`：通过。
- 双浏览器实测：
  - B 发送第一条，A 的手机 `⋯` 出现 `1`，菜单显示「城市会客厅 · 1」；
  - A 打开会话后角标清零，消息可见；
  - 会话打开时 B 再发一条，不产生未读；
  - A 关闭会话后 B 再发，角标重新变回 `1`；
  - 无控制台错误。
