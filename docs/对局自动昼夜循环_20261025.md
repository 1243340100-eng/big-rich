# 对局自动昼夜循环

- 对局从早晨开始，按真实经过时间循环：早晨 90 秒、黄昏 90 秒、深夜 90 秒；下一轮早晨进入下一天。时长集中在 `shared/worldTime.ts` 的 `TIME_OF_DAY_MS`。
- 服务器记录 `startedAt`，对局结束时记录 `finishedAt`。客户端连接及每 30 秒校准服务端时间，避免设备时钟差异导致时段不同。回合变化不重置昼夜。
- 开局时间随房间快照保存，重连和重启后沿用。旧快照仅补齐缺失字段，以最近回合开始时间作为升级后的起算点。
- 对局右上角显示时段、天数和下一时段倒计时，对局结束后定格。手机端打开地产或结算卡片时暂时隐藏时段卡，避免重叠。
- 城市模型页和大厅继续保留手动光影选择；对局通过 React Context 覆盖场景时段，不改写模型页保存的选择。
