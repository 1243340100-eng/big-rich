# 回合结算账单、钞票雨与音效

## 1. 触发时机

每个玩家自己的个人回合开始时，`beginTurn` 会写入新的 `lastSettlement`：

- 利息支出
- 地产税
- 维护费
- 支付过路租金（上次结算后）
- 地产经营收入（税后）
- 过路租金收入（上次结算后）
- 存款利息（转入存款）
- 本期净变化

账单覆盖“上次结算后”到本次结算之间的完整周期：过路租金在收付时已经进入现金，账单只做归集展示，不会在结算时重复打钱。客户端检测到 `lastSettlement.id` 变化后，打开结算账单并播放钞票雨和音效。刷新/重连不会重播旧账单。

## 2. 账单设计

`SettlementReceipt` 使用一张“城市财政系统”的纸质账单：

- 米白纸张、内框、底部锯齿边、条形码和流水号。
- 衬线体标题“回合结算单”，显示轮次和玩家名。
- 支出项红色、收入项绿色，虚线分隔。
- 本期净变化使用双线框大号数字。
- 右下角“盈余入账 / 支出结算 / 账目平衡”旋转印章。
- 底部显示当前现金余额、存款余额和编号。
- 桌面端固定在棋盘左上；小屏宽度自适应并可滚动。账单保持显示，直到玩家点击 × 关闭；新的回合结算会替换旧账单。

## 3. 钞票雨

- 账单为正时，24 张钞票从屏幕顶部飘落。
- 账单为负时，改为 24 个红色 `-￥` 符号飘落，不出现钞票。
- 每张钞票的横向位置、延迟、下落时长、漂移、旋转和缩放由账单 id 播种生成，同一条账单重渲染不会跳动。
- 钞票雨 `position:fixed`、`pointer-events:none`，不挡操作；约 4.2 秒后整体淡出。
- 开启“减少动态效果”时不渲染钞票雨，账单也取消入场/印章动画。

## 4. 音效

- 新增 `cash` 音效：低频“落账”音 + 五声高频金币/点钞声，使用 Web Audio 合成，无外部音频文件。
- 负账单改用低沉的 `settlement` 落账音，不播放金币声。
- 账单出现时播放一次；受“启用游戏音效”开关控制（默认静音）。
- 现有买入、升级、收租、赌场等提示音不变。

## 5. 代码位置

- 账单与钞票雨组件：`src/game/SettlementReceipt.tsx`
- 账单/钞票雨样式：`src/game/settlement-receipt.css`
- 入场音效：`src/game/feedback.tsx` 的 `cash` cue
- 渲染接入：`src/App.tsx` 的 `SettlementReceipt`
- 服务端结算字段：`server/engine.ts` 的 `beginTurn`

## 6. 测试

`tests/settlement-receipt.test.ts` 覆盖：

- 账单标题、轮次、玩家、各项明细、净变化、印章和流水号。
- 上次结算后的过路租金收入/支出会被归集进下一张账单，并只归集一次。
- 24 张钞票的稳定播种；减少动态效果时不渲染钞票。
- 负结算显示“支出结算”和红色金额。

全量 `npm test` 与 `npm run build` 通过后部署。
