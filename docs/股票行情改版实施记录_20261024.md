# 股票行情改版实施记录

依据《股票市场与行情显示改进方案_20261024.md》，本轮落实已确认的 P0 和纯前端 P0.5。估值模型、周期联动、财报、城市发展和 AI 定价等 P1/P2 规则建议继续保留在方案中。

## 界面与交互

- 六只股票使用独立的红涨绿跌、红盈绿亏语义；持平为中性色。涨跌带箭头、正负号及百分比。
- 全局 `.positive/.negative` 规则保持不变，股票外净资产和现金流仍沿用原色。
- SVG 行情图展示最多 30 轮已有价格记录，并在交易改变当前报价时补上实时端点；不将它伪装成逐笔行情或 OHLC。
- 图中包含 4 条网格、昨收虚线、渐变面积、最新价圆点及脉冲；窗口高低价与范围标识位于图下。
- 鼠标或触摸可选点；聚焦图表后，左右方向键、Home、End 可查看对应轮次和价格。
- 顶部行情条保持紧凑，原生悬停提示提供昨收及窗口高低价。
- 点击买入或卖出后先展开预览，提供 1 / 5 / 最大股数，显示预计花费或到账、手续费、卖出资本利得税、滑点、成交均价、成交后报价及现金余额。
- 最大可买股数同时考虑分步取整、手续费、滑点、1000 股上限和竞拍预留现金。
- 服务器确认持仓数量变化后自动收起交易预览；失败时仍保留输入与原有错误提示渠道。
- 持仓区域补充总资产占比、股息率和下次派息倒计时。
- 尊重减少动态效果偏好，关闭最新价脉冲。

## 规则边界

没有改动 `server/engine.ts`、服务器协议或 `Stock` 数据结构。报价预览通过测试与真实 reducer 的结算逐项对齐，正式成交仍以服务器结果为准。

复核方案时发现，原文把“房地产调整”的房价系数 0.7 误认成了其他股票的系数。源码实际是其他股票 0.96、银行/地产股 0.8、房价 0.7，原有“银行与地产股额外承压”的说明正确。已纠正方案摘要，没有调整游戏数值。

## 代码位置

- `src/market/Market.tsx`：行情条、股票卡、持仓与买卖预览。
- `src/market/StockChart.tsx`：纯 SVG 图形、悬停和键盘交互。
- `src/market/marketMath.ts`：绘图数据、前端费用预估、最大股数与派息轮次。
- `src/market/market.css`：股票专用样式与响应式处理。
- `src/App.tsx`：替换原有 Spark、Market 和行情条入口。
- `src/theme.css` / `src/theme-light.css`：深浅色股票专用颜色令牌。
- `src/main.tsx`：载入股票样式。
- `tests/market-display.test.ts`：显示边界和预览/结算一致性测试。

## 验证

- `npm test`：49 项通过，其中 7 项为本次新增。
- 所有职业、六只股票、买入/卖出、1/5/25/1000 股组合的现金、费用、税款及报价，与原有服务器结算一致。
- 覆盖空历史、单点、平盘、价格 1/500、实时端点、数量非法、买不起、持股不足、竞拍预留及负现金部分卖出等边界。
- `npm run build` 通过；仍有原共享 3D 包的体积提示。
- 浏览器使用独立 `PORT=3002`、独立 `DATA_DIR` 和合成房间，不读取或改写原有 `data/rooms.json`。
- 实际完成测试买入和卖出，确认报价、图表端点、持仓与现金实时变化，成交后预览关闭。
- 颜色实测：股票上涨 `rgb(179,86,62)`、下跌 `rgb(47,125,91)`，顶部与卡片一致；股票外净资产正收益仍为绿色。
- 六张图均有 4 条网格和昨收线；开局六只股票的单点数据绘制为水平线与一个最新端点，没有 NaN。
- 390px 下图表高度为 50px；390/320px 均未发现卡片或页面横向溢出。窄屏通过浏览器视口检查，未做实体手机性能测试。
- 桌面和窄屏检查未捕获浏览器警告或错误。
