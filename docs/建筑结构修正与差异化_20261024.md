# 建筑结构修正与差异化 · 2026-10-24

## 修正范围

- 证券交易所：移除原来穿入主体的三角锥，改为落在屋顶平台上的阶梯冠部、固定行情屏和带底座的行情箭头。
- 市场消息及其他消息格：用落地立柱承托公告栏，屋顶桅杆与顶饰相连，移除旧的悬空横线和吊饰。
- 城市银行及金融服务站：重建基座、列柱、檐梁和坡屋顶，统一它们的接触高度；徽章限制在檐梁范围内。
- 中央银行大楼：后墙窗饰贴回墙面，侧廊柱脚落地、檐口对齐附楼；钟楼平台降低至屋顶以下并增加支撑。去掉重复钟面及多余高架构件；补齐台阶和长椅支腿。
