# 股票规则与详情实施记录

用户已明确批准同时实施 P1/P2：估值、经济周期与城市联动、财报、AI 交易和详情图。此前 P0/P0.5 记录保留为阶段记录。

## 实际改动

- 六股独立元数据和定价参数，银行/食品较稳，能源/科技波动较高，地产和文旅各有周期暴露。
- 每轮价格向合理价值回归 35%，再叠加行业噪音和全球事件冲击；价格仍限定为 1–500。合理价值来自基础价、周期、利率、房价指数和城市发展，不使用近期股价反推。
- 玩家只看到“偏低 / 合理 / 偏高”区间。价格低于合理价值的 90% 为偏低，高于 110% 为偏高。精确估值不放进服务器广播。
- 银行参考全城存款、贷款与抵押规模；地产参考全城开发；能源参考未来产业，科技参考创意工坊/科技园区/云端总部；食品和文旅参考消费与文旅设施。发展加成统一上限 10%，与土地归属分布无关。
- 事件直接决定周期：繁荣/AI→繁荣，危机→危机，泡沫/能源危机→过热，地产调整→衰退，降息→复苏。保留既有工资、租金和利息公式，使它们读取同一个周期。
- 第 5/10/15……轮发布财报，影响范围 ±7%；派息按除息前报价和原股息率计算、扣 10% 股息税，报价同步扣除税前股息。每轮结算只执行一次。
- AI 优先处理土地、升级和偿债。普通调仓每个自己的回合至多一次、每次至多 3 股；保留至少 80 万现金，负债时不新增持股，买入总股票占比不超过 20%、单股不超过 12%。明显高估、仓位偏高或现金偏少时小量卖出；现金为负时可绕过普通调仓限制应急变现。
- 详情弹窗提供 5/10/30 轮图、真实轮次、横纵十字线、全球事件/财报/派息标记及消息列表，包含持仓、估值、影响因素与同一套买卖预览。
- 支持方向键/Home/End 检查图表、Escape 关闭、Tab 焦点循环及关闭后焦点恢复。沿用股票专用红涨绿跌。

## 兼容与启动

- 旧存档只补充版本、收盘轮次、消息和估值字段；保留现金、贷款、存款、持仓、持仓成本、当前报价与原有历史。不会补造旧财报或旧派息，也不会重发迁移所在轮的股息。
- 新版 `/api/health` 返回 `marketRules: 2`，房间状态包含 `marketVersion: 2`。
- 正在运行的非 watch Node 服务不会自动加载改动。若界面提示“当前连接使用旧版股市规则”，先在原服务器窗口按 Ctrl+C 正常关闭，再运行 `启动游戏.cmd`；浏览器随后刷新或重连。不要在游戏进行中强制结束 Node 进程。
- 原用户服务未被强制重启，原用户存档未被工具读取或改写。浏览器验收使用独立 3002 端口和独立测试目录。

## 收益抽样

运行 `npx tsx artifacts/market-rules-review-20261024/balance-check.ts` 可复现。30/50 轮 × 未开发/逐步开发 × 各 1000 个种子，共 4000 组路径。每股买入 10 股、持有到局末后按当前结算公式卖出；计入手续费、滑点、资本利得税、税后股息，开发由脚本外生推进。每股单独账户，组合为等股数而非等金额。

| 场景 | 组合收益 P5 | 中位数 | P95 |
| --- | ---: | ---: | ---: |
| 30 轮，未开发 | -16.35% | 5.54% | 23.42% |
| 30 轮，逐步开发 | -9.70% | 13.86% | 32.97% |
| 50 轮，未开发 | -6.39% | 12.62% | 27.24% |
| 50 轮，逐步开发 | 0.80% | 21.38% | 37.14% |

样本报价范围 4.23–34.35 万，没有因随机游走长期停留于 1 或 500 的现象。完整明细见 `artifacts/market-rules-review-20261024/balance.json`。

这些结果只是固定持有策略的数值抽样，不包含人类择时、工资、租金与借贷，也不能证明所有策略下地产始终优于股票。仍应通过真实多人对局观察市场与地产的整体平衡。
