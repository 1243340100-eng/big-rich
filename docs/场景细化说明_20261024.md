## 实现与验证

新增细节位于 `src/scene/detailGeometry.ts` 和 `src/scene/CityDetails.tsx`，由 `src/Board.tsx` 集成。几何按五类材质合并，避免每根栏杆、每块铺砖单独创建绘制调用。喷泉水滴采用 48 个实例。

全城 Lv.3 的新增静态细节实测为 **7,455 个构件、118,428 个三角面、176 个合并网格**，不含原有场景及动态水滴。该统计是几何预算，不代表整场景绘制调用数或设备帧率。

`npm test`：20/20 通过，包括所有地产 Lv.0–Lv.3 的顶点有效性、材质属性完整性、范围与预算检查，以及既有规则和联网测试。`npm run build`：TypeScript 与生产构建通过；仍有共享三维代码包体积提示。

已在浏览器检查住宅、商区、海湾、产业区和广场近景，覆盖四个建筑等级；检查期间未捕获到浏览器 warning/error。不同显卡和移动设备上的实际帧率尚未专项验收。
