# 中央广场建筑升级

地图中央的星海城市银行与前广场已整体更新，首页、对局地图和城市典藏共用新版模型。

- 六根通高凹槽石柱，带柱础、涡卷柱头与连续檐梁；三角山花增加城市徽章，门廊楣部加入银行铭牌。
- 扩大主厅、双侧翼楼与基座。前后使用拱形暖光窗，侧面补充窗框、横档、墙角石和水平墙面分缝。
- 钟楼改为四面表盘，包含黄铜边框、时标、指针和中心轴；上部增加采光鼓座、铜色穹顶、十二道铜肋和顶饰。
- 主厅与侧翼采用铜绿色坡屋顶，增加屋面拼缝、滴水边、分层檐口与金属檐齿。
- 新增七级宽台阶、贴地的阶梯栏杆基座、周边石栏杆、花钵与修剪绿植；广场增加双侧旗幡、铺地镶嵌和喷泉饰边。
- 调整后侧花坛与树木，留出侧翼空间；保持六名广场行人的通道及现有喷泉、飞鸟。中央建筑近景按新版体量重新取景，并适配窄屏。

主体含 665 个命名部件，合并为 4 组材质网格，共 24,458 个三角形。全城几何预算检查已纳入中央建筑。

76 项测试通过，生产构建通过；新增测试覆盖主体边界、结构支撑连续性、四面表盘、拱窗贴墙和全部广场行人的实际碰撞范围。已在浏览器检查前、侧、后立面、城市全景及 390 像素手机预览，控制台无错误。
