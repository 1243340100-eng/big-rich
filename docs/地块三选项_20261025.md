# 地块落点三选项

2026-10-25。

普通无人持有地块现在提供三个主操作：

1. **购买**：按当前市场买价及反垄断税结算，继续使用购买确认框。
2. **低价拍卖**：按地块基础地价的 **70%** 起拍，保留两位小数；起拍金额显示在按钮上。所有玩家可参与，拍卖面板在发起后自动打开。首次可报起拍价，此后最低加价 1 万；成交仍计入反垄断税。
3. **跳过不买**：不扣钱、不转移归属、不触发拍卖，直接回到本回合管理阶段。

例如基础地价 100 万的地块，起拍价为 70 万。起拍基数是基础地价，不随房产指数变化。

商业地块的定金预定保留，入口移至“更多操作 → 预定地块 · 30% 定金”，主操作栏保持三个选择。已被预定的地块继续允许全款截胡或跳过，拍卖按钮禁用；跳过不会取消他人的预定。破产清算拍卖沿用原有的半估值起拍规则。

机器人继续优先购买或办理商业预定；不能覆盖起拍金额、税款与现金缓冲时可跳过。
