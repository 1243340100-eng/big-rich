# 地块简报交互

- 桌面鼠标悬停在地块建筑、底座或地名时，左上角显示简报；移开隐藏。悬停不改变选中地块或镜头。
- 点击地块／地名可固定简报，手机端使用点击查看。点击空白处或关闭按钮取消；触屏拖动棋盘不会误选。
- 简报显示地块名称、等级／抵押状态、所属玩家、作用与停留后果。空地说明当前价格与拍卖，非本人地产显示当前应付租金，自己的或已抵押的地产明确说明不付租金。
- 起点、银行、交易所、税务、事件、捷径入口／出口和赌场分别说明用途及效果；公共地块标为“城市公有 · 不可购买”。
- 点击自己地产后保留升级、资产管理入口；赌场保留入场入口。预览期间暂时收起结算回执，避免挡住简报。
- 数据直接读取最新房间状态并使用共享市值／租金公式；查看简报本身不发送对局操作。

## 文件

- `src/game/tileInfo.ts`：36 个地块的只读说明。
- `src/game/TileInfoPanel.tsx`、`tile-info.css`：简报与响应式布局。
- `src/Board.tsx`：悬停回调、触屏区分、离开清理与空白处取消。
- `src/App.tsx`：悬停预览／点击固定及原有操作入口。
- `tests/tile-info.test.ts`：所有地块、当前报价、实际买入／租金扣款、抵押及特殊地块。
