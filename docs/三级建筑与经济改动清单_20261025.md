## 0. 前置修复：卖给银行的白刷钱漏洞（必须先做）

### 问题

`case 'sellProperty'`（[engine.ts:115](../server/engine.ts#L115)）回收价 = `估值 × 0.7`，而买入价吃房产指数、升级费不吃。三段相接：

```
买入   = price × index
升满   = price × 0.45 × 3 = price × 1.35     ← 不吃 index
卖银行 = price × 2.8 × index × 0.7 = price × 1.96 × index
```

盈利条件 `1.96 × index > index + 1.35` → **`index > 1.406`**。

而 `propertyIndex` 上限是 2.5（泡沫事件 ×1.30 可叠两次），所以指数一旦过 1.41，**「买入 → 升满 → 卖银行」是零风险套利**，index=2.0 时每块地每次净赚 0.57 倍地价。

### 修法

给回收价加一条**投入成本上限**，让任何情况下卖出都是亏损：

```ts
const invested = TILES[a.tileId].price * s.economy.propertyIndex
               + TILES[a.tileId].price * .45 * a.level;
const proceeds = money(Math.min(propertyValue(s, a) * .7, invested * .85) - a.mortgage);
```

- 上限是投入的 85%，所以任何 `index`、任何 `level` 下卖出必亏 15%
- 不新增字段、不改存档结构
- 正常玩（持有收租）完全不受影响：`index ≤ 1.5` 时 `估值 × 0.7` 本来就低于上限，`min` 不生效

**穷举验证**（index 取 0.45–2.50 共 42 档 × level 0–3，共 164 组）：

| | 可套利组合数 | 最好情况 |
|---|---:|---:|
| 现有规则 | **39 / 164** | 正值，最差处每块净赚 0.57 倍地价 |
| 修法后 | **0 / 164** | −13.37 万（仍为亏损） |

也就是说现状不是"极端情况才会触发"，而是**约 24% 的指数/等级组合都能白刷**。

- [ ] 改 `engine.ts:115` 的 `proceeds` 计算
- [ ] 新增测试：对 `index ∈ [0.45, 2.5] × level ∈ [0,3]` 全组合断言「卖出所得 < 买入价 + 升级费」

### 1.4 二手保值（抵押率）


## 3. 反垄断法

### 3.1 共用计税函数

`shared/finance.ts` 新增：

```ts
export function antitrustTax(s: GameState, buyerId: string, tileId: number) {
  const district = TILES[tileId].district;
  const held = s.properties.filter(p =>
    p.owner === buyerId && TILES[p.tileId].district === district).length;
  return held >= 2 ? money(TILES[tileId].price * (held - 1) * .25) : 0;
}
```

基数用**地价**而非估值，避免被房产指数放大。

| 该街区已有 | 买第几块 | 附加税 |
|---|---:|---:|
| 2 | 第 3 块 | +25% 地价 |
| 3 | 第 4 块 | +50% 地价 |
| 4 | 第 5 块 | +75% 地价 |

税款**入银行**，不分给其他玩家（分给对手会变成"买得越多大家越赚"，动机是反的）。

### 3.2 三个入口都要接（漏一个就失效）

| 入口 | 代码 | 处理 |
|---|---|---|
| 主动买入 | [engine.ts:108](../server/engine.ts#L108) | 付款 = `propertyValue + tax`，现金不足要正确报错 |
| 拍卖成交 | [engine.ts:62](../server/engine.ts#L62) | 赢家额外扣 tax；**竞拍 UI 必须提前显示**，否则是暗扣 |
| 玩家交易 | [engine.ts:79](../server/engine.ts#L79) `transferLeg` | 受让方付 tax，需校验现金 |

> 拍卖是**可被主动利用的避税通道**：踩到地不买 → 流拍进拍卖 → 再去拍下。所以这条不能省。

- [ ] 加 `antitrustTax()`
- [ ] 买入接入
- [ ] 拍卖接入（含 UI 提示）
- [ ] 交易接入（含现金校验）

## 4. 配套：街区垄断加成

`shared/finance.ts` 的 `propertyRent` 里按 `district` 计数：

|---|---:|

| 5 块 | +60% |

- [ ] 垄断乘数
- [ ] 与 `district` 字段联动（该字段目前**未被 server 使用**，这是它第一次有机械意义）

> 一次性购买税压不住持续收益：3 块地垄断 +30%，一个街区 30 轮被踩 8~12 次可多收 86~130 万，而一次性税约 60 万。**若实测仍滚雪球，追加"持有税"**（每回合按超额地块收），不要靠抬高购买税解决。
