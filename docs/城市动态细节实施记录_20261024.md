# 城市动态细节

## 新增效果

- 24 名街边行人沿外围步道散步，6 名广场行人在银行台阶与喷泉之间走动。行人有摆臂、迈腿和轻微起伏，衣服、肤色、发色与手提包有所区别。
- 行走路线采用两条平行步线及圆弧回转，避开车道、地块、街边设施、银行台阶和喷泉；同一路线等速错开间距，避免相向穿模。
- 未来工场两根烟囱持续排出淡烟，烟团会向上升起、轻微漂移、扩大并淡出。出口随建筑等级对齐实际烟囱顶部。
- 艺术剧院门廊灯泡依次明暗变化，入口有柔和暖光；Lv.2 起，顶部加入两束缓慢扫动的灯光。星光影院 Lv.1 起启用迎宾跑马灯。
- 绿色能源站的三叶风机围绕现有轮毂转动，替换原来的静态叶片，保留塔架和机舱。
- 广场上方新增 4 只缓慢盘旋、拍翅的飞鸟，证券交易所塔灯轻缓明暗变化，喷泉水滴与城市动画使用同一时钟。
- 首页展示城市也可看到工场、剧院等动态建筑；对局内按真实购买和建筑等级显示，空地仍保持空地。

## 动画与开销

行人主体和头部使用两组实例网格；烟雾使用一组 24 个柔边面片，门廊灯泡各使用一组实例网格。动画只更新矩阵、颜色与透明度，避免逐帧更新 React 状态；装饰物不参与鼠标射线命中。

系统启用“减少动态效果”时，新行人、飞鸟、风机、灯光和喷泉动画停止，烟雾隐藏。后台标签暂停城市时钟，返回时限制单帧追赶，防止长时间跳动。

建筑升级时暂停排烟与剧院扫光；风机保留并停止旋转。待脚手架与幕布动画完成，再恢复日常活动。工厂与风机的安装位置共享模型参数，避免升级后错位或出现双层叶片。

## 验证

- 72 项测试通过，生产构建通过。新增检查覆盖所有行人的路线边界、相互间距、回转连续性、原有静态结构保留、烟囱/轮毂/灯具位置、烟雾生命周期、风机旋转包围范围及减少动态/后台暂停的时钟逻辑。
- 实际浏览器已检查工场烟雾、剧院灯光、能源风机、广场行人与飞鸟、全城预览及施工期间烟雾隐藏/恢复；390 像素手机预览无横向溢出，控制台无着色器错误。减少动态逻辑由自动化测试覆盖，未更改用户的操作系统设置。
- 独立使用 3002 端口和测试数据目录；用户对局快照未被读取或改写。保留原有道路、车辆、地名与建筑升级回归检查。
- 截图保存在 `artifacts/city-life-review-20261024/`。后台浏览器存在帧率节流，因此未将截图时的 FPS 当作实际设备性能结论；低端手机仍应以真实运行体验为准。
