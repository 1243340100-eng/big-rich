# 周边城市群 · 城市碗实施记录

依据 `周边城市群_城市碗方案_20261025.md` 实施。棋盘几何、资产、规则、房间存档和默认镜头位置保持原样；只添加外围场景层，并调整投影落点和拉远后的取景。

## 实现内容

| 阶段 | 结果 |
| --- | --- |
| P0 | `y=-0.30` 的连续地面、方形环街与铺装、70 栋近带体块；接触阴影移至 `y=-0.29`、范围 30、透明度降至原值的 55% |
| P1 | 60 栋中带体块、42 座近带坡屋顶、四方位街区配色及明度抖动 |
| P2 | 90 栋远带体块，半径 55–90、高度不超过 18；默认隐藏，拉远逐步显现；半径 38–55 留作环城水系，四向主路及桥面连接内外环 |
| P3 | 材质窗格与夜间亮窗、平屋顶边缘压线、两处低矮屋顶设备；全部复用既有灯光，没有新增光源或额外绘制批次 |

布局由固定种子生成，城市层没有使用 `Math.random()`。全部外围对象关闭射线拾取、投影和受影，不阻断棋盘交互。建筑单独近看时隐藏外围城市，并恢复原有接触投影与雾范围。

## 实拍后采用的参数调整

方案给出的是初始值，以下调整用于满足其“不遮挡、不抢戏、看不到世界边缘”的验收目标：

1. **方形边界。** 原棋盘半宽 11.4，四角的径向距离约 16.12，直接使用圆环会遗漏角部。环街改为半宽 11.4–15.5 的方形环带，按完整楼体占地检查是否伸进环街和棋盘。
2. **体块尺度。** 保留宽度区间，近／中／远带分别乘 `0.22 / 0.24 / 0.24`，再做占地排斥检测，避免按原始宽度生成时互相穿插。地块网格为 80×80 候选点，确定性挑选出 70／60／90 栋。
3. **高度与画面上沿。** 总高度包含屋顶，既受 `0.9 × (r − 11.4)` 限制，又按距方形棋盘的净空与默认画面顶边进一步夹紧；近／中带高度起始值分别乘 `0.65 / 0.55`。默认视角实拍的顶部保留雾色，不形成高楼墙。
4. **远景取景。** 默认镜头仍为原位置与 38° 视场。仅在拉远、远带显现时平滑扩展视场，距离 140 时达到 82°，完整容纳城市碗。重置视角会立即恢复 38°。
5. **雾与地面。** 城市材质使用现有场景的同一雾色，在默认构图下更早融入雾中；主棋盘的默认雾仍为 65–135。拉远时延长雾区，避免距离 140 已超过原 far=135、连棋盘中心也被吞掉。承托地面半径从初始 120 调至 220，城市体块仍止于 90；扩大同一组地面三角形不增加面数，避免宽景时露出近侧的圆形地面边缘。
6. **Windows 模块名。** 几何文件为 `distantCity.ts`，渲染文件采用 `DistantCityLayer.tsx`，避免 Windows 下 `DistantCity` 导入优先匹配同名 `.ts` 引发大小写冲突；导出组件仍名为 `DistantCity`。

所有主要布局、尺寸、配色、高度、雾与宽景参数集中在 `src/scene/distantCity.ts` 的 `CITY`；`CITY.enabled=false` 可关闭整层并恢复原投影和取景行为。`CITY.stage` 的 0／1／2／3 可用于逐阶段查看。

## 性能与检查结果

- 城市主体 220 栋，坡屋顶 42 座，屋顶设备 2 处，共 **3,188 个三角面、4 次绘制**。几何属性与实例矩阵／颜色缓冲低于 1 MB，无外部贴图。
- 已把外围城市计入原 `model-detail` 回归预算。Lv.3 静态细节测试合计 **136,482 三角面、183 个合并批次**，仍低于 400,000／200 的既有上限。
- 全量 `npm test`：**117 项通过**。最终地面范围调整后再次运行 10 项几何／预算相关检查，全部通过。
- `npm run build`：TypeScript 与生产构建通过，保留原有大型 Three.js 资源包提示。
- 浏览器在隔离测试端口 33127 检查早晨／黄昏／深夜、竖屏、四次环绕截图、拉远 140、连续 5 次刷新布局一致、外围点击不选中、棋盘地名点击正常，以及独立模型近看；页面与控制台错误为零。
- 视线测试在桌面及竖屏默认镜头下每隔 10° 环绕取样，检查射向棋盘四条边的视线，未与外围体块或屋顶设备相交。另检查宽景时所有城市体块均位于画面内。

## 文件与运行

- `src/scene/distantCity.ts`：参数、固定布局、地面／街道／屋顶几何、雾范围、远景显现与宽景视场。
- `src/scene/DistantCityLayer.tsx`：4 个渲染对象、实例矩阵、时段与雾的接入。
- `src/scene/cityMaterial.ts`：背景雾融合、窗格、亮窗和屋顶压线。
- `src/scene/cameraFraming.ts`：抽取原有默认镜头距离公式，供外围层复用。
- `tests/distant-city.test.ts`：布局、占地、遮挡、预算、雾、远景、拾取及宽景回归。
- `artifacts/distant-city-20261025/`：实机截图、浏览器检查脚本、构建与测试日志；`backup/` 保留施工前的文件。

本次只改前端场景并已重新生成 `dist/`。刷新现有游戏页面即可加载城市碗，无需重建房间或重启服务器。
