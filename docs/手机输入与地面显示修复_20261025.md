# 手机输入与地面显示修复

## 输入时页面放大

原先昵称、聊天、银行、交易和股票数量输入的字号为 11～13px。iPhone Safari 会对小于 16px 的输入框自动放大，收起键盘后可能保留缩放。

新增 `src/mobile-input.css`，对窄屏和触屏设备的文本、数字输入、下拉选择及多行输入统一设置至少 16px；覆盖各组件的局部小字号设置，同时给聊天对象选择框留足宽度。桌面宽屏字号保持原样，保留浏览器的手动缩放。

生产构建已更新。手机刷新页面加载新资源后生效；已经处于异常放大状态的旧页面也需要刷新一次。

## 道路与中央广场

道路的多个薄层以及停车位接缝存在相近或相同深度。手机竖屏总览镜头更远，会放大深度缓冲精度不足的影响。

- 保留道路材质的分层深度偏移，让路面、转角、停车区、标线稳定排序。
- 相机近裁剪面按观察距离在 0.5～4 之间调整，远裁剪面为 420，兼顾近看建筑和远看城市。
- 中央广场交叉道路改为边缘拼接，移除草坪下面多余的铺砖，把黄铜嵌条移回步道。
- 接触阴影平面与外围路面拉开距离。
