# 经济漏洞修复记录

2026-10-25。对应本轮核查确认的重组、玩家股票交易、过桥存款利差与构建体积问题。

## 已实施的规则

### 过桥资金

- 每个个人回合按未偿本金收取 **2% 利息**，计入服务器结算、现金流预览与银行说明。活期利率仍为 1%。原到期轮及逾期 20% 罚息保留。
- 新增永久的 `bridgeLoanUsed` 标记。借款时设为已用，还清、重组、断线重连、服务重启均不恢复次数。
- 旧存档中正在使用的过桥贷款会迁移为“本局已用”，不改变本金或余额。旧记录如果已经还清且没有使用标记，无法可靠还原历史次数；迁移时保留一次新规则下的额度，此后永久锁定，避免误封从未使用过的玩家。
- 反例验证：80 万存六次仍得到 84.92 万，但同期支付 9.60 万利息，取款并归还本金后净资产比借前减少 **4.68 万**，不能再赚原先的无风险利差。

### 重组

- 过桥本金并入本人的普通债务和抵押债务，参与资产清算和剩余债务 80% 减免，然后清除独立的过桥合同，避免残留另一套债务。
- 取消本人的全部预定权，已付款没收，不退入现金，也不转给其他玩家。其他玩家的预定继续有效。
- 使用同一个共享结算报价生成筹资面板预览和服务器结果，显示取消数量、没收金额与合并后的债务。
- 重组不恢复已经用掉的过桥次数。

### 玩家间股票交易

- 股票腿按成交时的**即时市值**计税；赠与、低价转让和资产交换也适用，不能用声明低价消除税基。
- 转出方支付职业对应的手续费（标准 1%，投资经理及程序员科技股为 0.5%），并对市值超过原持仓成本的部分收 10% 盈利税。
- 接收方支付同样适用职业优惠的接收手续费。接收成本记为“即时市值 + 接收手续费”，旧浮盈已经在转出端纳税，避免未来市场卖出重复纳税。
- 同时冻结交易双方原始持仓成本，再执行两条转移腿，避免双方交换同一种股票时因执行顺序污染成本。
- 发出和接受提案均重新校验现金、全部税费与竞拍预留；报价变化后重新计税。界面显示双方手续费、盈利税及成交后现金。税费进入银行。
- 玩家协商交易不产生市场滑点，也不改变市场报价；市场滑点仍仅适用于市场订单。
- 示例：10 股科技股市值 200 万、原成本 100 万，双方均无职业优惠，约定支付 200 万。卖方收款净额 **188 万**，买方总支出 **202 万**，股票新成本 **202 万**。
