# 建筑升级施工动画

20 栋可升级地产统一接入施工演出，真实对局中等级增加会自动触发。购买后的初次出现、打开现有对局和相同等级的状态同步不会播放。

## 动画顺序

总时长约 4.15 秒，按旧、新模型的较大高度自动计算脚手架层数。

1. 0～1.22 秒：从地面开始逐圈搭建脚手架，每层包含角柱、横杆、交叉斜撑与踏板，出现时略微弹过头。
2. 1.22～1.96 秒：带褶皱、包边和封顶的幕布从顶端落下，包住脚手架与整个建筑。
3. 2.08 秒：在幕布完全遮挡、保持不透明时切换建筑等级。
4. 2.48～3.22 秒：幕布向上收起并消失；脚手架随后淡出。
5. 3.14～4.15 秒：揭幕后建筑进行压扁、拉伸、衰减回弹，配合少量金色光点与地面光环，最后恢复原始尺寸。

等级的经济效果仍由原有服务器逻辑立即结算，动画只管理客户端显示，不阻塞下一步操作。

## 状态与显示处理

- 连续升级时先完成正在播放的一次，再合并播放到最新目标等级，避免中途改变脚手架尺寸或回到旧等级。
- 所有权或房间变化、等级下降时取消旧动画并显示当前状态。
- 系统启用“减少动态效果”时直接显示新等级。
- 施工几何不参与鼠标射线检测，不抢占地块与地名牌交互。
- 脚手架底脚接触地块表面；施工外壳和建筑回弹保持在地块附近的预留范围内。
- 模型查看页可通过等级按钮触发，也可点击“重播升级动画”。高塔预览镜头按满级施工高度留出空间。

## 实现

- `src/scene/upgradeAnimation.ts`：时间线、遮挡切换时点、连续升级处理、弹性曲线。
- `src/scene/constructionGeometry.ts`：合并的脚手架层与四面闭合的褶皱幕布。
- `src/scene/UpgradeableBuilding.tsx`：旧、新模型显示协调、逐帧动画、资源清理与动态效果偏好。
- `src/Board.tsx`：统一接入可购买建筑，传入房间和所有权标识。
- `src/ModelViewer.tsx`、`src/model-viewer.css`：升级动画重播入口。

每栋施工中的脚手架使用一个实例化网格，幕布使用一个合并网格；庆祝光点与光环各使用一个网格。结束后施工组件卸载并释放几何资源。
