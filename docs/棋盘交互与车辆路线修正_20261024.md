# 棋盘交互与车辆路线修正 · 2026-10-24

## 使用

- 默认使用自动地名：优先显示选中、悬停、当前落点，其余标签依据镜头距离和画面中心位置筛选，并避免相互覆盖；标签始终朝向镜头，保持可读尺寸。
- 棋盘右上角可切换“地名：自动 / 全部”。
- 已购地产用业主颜色描边；“我的地产”定位第一处地产，并突出自己拥有的地块。没有地产时给出提示。
- 点击左侧玩家名片（键盘 Enter / 空格也可）可定位对应车辆所在地块；当前行动玩家与自己的车辆有独立名称标识。
- 重置视角会清除选中和我的地产筛选。

## 路线与停车

- 外环路面范围为 8.9–10.48，主行车线半径 9.98；每个转角有显式拐点。
- 每个地块设置 8 个互不重叠的固定垂直车位，停靠半径 9.22，车位间距 0.21。汽车倒车退出车位，在行车道上行驶，再驶入目标车位。
- 两条捷径改为建筑旁的道路；入口与出口从地块间隙通过，并为路缘留出开口。绘制道路和汽车行驶共用坐标。
- 调整原来占据行车空间的路灯、树木和内部小公园。
- 移动动画按接收顺序排队，避免机器人或快速结束回合造成多车同时穿行；刷新后直接恢复对应车位，不重播旧路线。
- Canvas 保留车辆坐标和动画队列的 DOM 诊断信息，与原有渲染指标一起用于验收。

## 验证

- npm test：26 项通过。新增检查覆盖四个外环拐角、所有地块的 8 人同格停靠、两条捷径与建筑占地的间距，以及行驶车辆与各地块已停放车辆的间距。
- npm run build：TypeScript 与生产构建通过。仍有原有三维共享包体积提示。
- 浏览器检查：自动/全部地名切换、购买后的业主边框与“我的地产”定位、玩家名片定位、8 人起点排列、掷骰后驶入对应车位，以及手机和桌面布局。最终构建未捕获浏览器 warning/error。
- 8 人起点实际渲染坐标为 x = -8.735、-8.525、-8.315、-8.105、-7.895、-7.685、-7.475、-7.265，z 均为 9.22；一次两点移动后首车位于 (-4.735, 9.22)，其余车辆保持原车位。
- 路线检查按模型车身外包范围进行，不代表新增了物理引擎；跨显卡帧率尚未专项测试。
- 测试服务使用独立目录 artifacts/board-navigation-review，未修改正式 data/rooms.json。
