# 移动端紧凑账单、地块详情与性能模式

## 1. 结算账单

**手机（≤759px）默认折叠**，只保留：

- 第几轮 / 玩家名
- 本期净变化（盈亏）
- 现金余额 / 存款
- “点击展开全部明细”按钮

点开后恢复完整账单：利息、地产税、维护费、经营收入、过路租金、存款利息、净变化、余额、印章、条码和编号。桌面端仍默认完整账单。

实现位置：`src/game/SettlementReceipt.tsx`、`src/game/settlement-receipt.css`。移动状态由 `useMobileLayout()`（`prefers/max-width:759px`）决定。

折叠时同时隐藏地块详情面板，避免账单和地块卡片叠在一起。

## 2. 地块详情

**手机点击地块后默认紧凑**，只显示：

- 地块名 / 等级
- 所属
- 当前租金（地产）
- 经营收益（地产）或地块作用（公共地块）
- 最多两个标签
- “展开全部信息”按钮

展开后恢复完整内容：作用说明、停留效果、市值/租金/经营收益、升级/抵押/出售/赌场等操作。桌面端和悬停预览保持原样。

实现位置：`src/game/TileInfoPanel.tsx`、`src/game/tile-info.css`。

## 3. 性能模式

入口：对局内右上角 `⋯` → **反馈与性能** → **性能模式（移动端省电）**。

开启后：

| 项目 | 普通模式 | 性能模式 |
|---|---|---|
| 棋盘 DPR | 最高 1.6 | 最高 1.15 |
| 动态阴影 | 开启 | 关闭 |
| 接触阴影 | 每帧 512 | 单帧 256 |
| 城市装饰动画 | 运行 | 冻结 |
| 行人 / 鸟 / 喷泉水滴 | 显示 | 隐藏 |
| 建筑动态装饰（烟、风机、跑马灯、光束等） | 显示 | 隐藏 |
| 金钱雨 / 彩带 / 赌场粒子 | 显示 | 隐藏（CSS） |
| 偏好持久化 | — | `localStorage: capital-performance-mode = true` |

关闭后全部恢复。普通桌面模式不受影响。

实现位置：`src/game/preferences.ts`、`src/Board.tsx`、`src/scene/SceneLighting.tsx`、`src/scene/CityMotion.tsx`、`src/scene/CityDetails.tsx`、`src/scene/CityLife.tsx`、`src/mobile-layout.css`。
