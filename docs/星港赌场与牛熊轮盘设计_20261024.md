# 星港赌场与牛熊轮盘设计

- 日期：2026-10-24
- 状态：已按推荐配置实施 P0–P3，见 [实施记录](./星港赌场与牛熊轮盘实施记录_20261024.md)
- 目标：在地图中加入一座气派的赌场，提供一局节奏快、可选择、长期数学期望为负的轮盘玩法
- 关联文档：[回合行动与现金流体验改进方案](回合行动与现金流体验改进方案_20261024.md)

## 1. 摘要

赌场命名为 **星港赌场**，核心玩法为 **牛熊轮盘**。

它不是“押红黑，中了翻倍”的传统轮盘，而是一个带 **见好就收** 决策的推注轮盘：

1. 玩家用现金买入筹码。
2. 转动轮盘：可能爆仓，也可能让当前筹码上涨。
3. 每次安全转动后，玩家可以 **落袋离场**，也可以 **继续把全部筹码押上去再转一次**。
4. 爆仓则本轮筹码归零；达到上限则强制结算。

这个玩法有三个好处：

- 每一转都有明确的风险和收益，不需要记复杂赔率。
- 玩家的真实决策是“现在收手，还是贪一次”，比单纯押颜色更有参与感。
- 每转数学期望低于 1，且上限、次数和筹码限制明确，长期无法稳定套利。

> 核心定位：赌场是高风险娱乐和现金回收池，不是稳定的赚钱途径，也不会成为地产和股票之外的“无风险套利工具”。

## 2. 设计目标与非目标

### 2.1 目标

- 给地图增加一个有辨识度的娱乐地标，补足“海湾文旅”区域的夜生活氛围。
- 给玩家一个不同于地产、股票的高波动选择。
- 让赌场有明确的视觉、声音和节奏记忆点。
- 用规则保证长期负期望，而不是靠隐藏作弊。
- 不迫使玩家赌博；不赌博也能正常完成回合。

### 2.2 非目标

- 不做真实货币赌博。
- 赌场内不提供贷款、取存款、抵押地产或出售资产的追加筹码入口；入场前已有的现金可以使用。
- 不允许抵押地产、股票或未来工资下注。
- 不做玩家对赌、坐庄、赌场股权或分红。
- 不做自动连转、自动追损、自动加注。
- 不做“差一点就中”的诱导式近失动画。
- 不通过动态调低赔率针对赢家。

## 3. 地图落位

### 3.1 推荐位置

将现有 **19 号地块「市场消息」** 替换为：

```text
星港赌场
区域：海湾文旅
类型：casino
坐标：保持原 19 号地块位置
```

推荐理由：

- 19 号位于海湾文旅一带，靠近艺术剧院、海湾酒店和滨海度假村，娱乐业气质最匹配。
- 当前棋盘有四个「市场消息」事件格（2、16、19、27），替换其中一个，事件数量仍保留三个。
- 不减少可购买地产数量。
- 不修改 `nextTile` 环形路径和 32 格主路径，不需要重做移动系统。
- 该位置临街，适合做正门、雨棚、红毯和屋顶轮盘招牌。

如果不想减少事件格，备选方案是替换 25 号第二座「城市银行」；但这会减少银行节点，不如替换重复事件稳妥。

### 3.2 地块规则

- 赌场是特殊地块，不可购买、不可升级、不可抵押。
- 玩家停在赌场时，不强制赌博。
- 只允许 **当前玩家、现金非负、且本回合停在这里** 时进入。
- 进入赌场不消耗掷骰机会；离开后仍处于管理阶段，可以结束回合。
- 每次停留赌场只允许一次入场；离场、爆仓或现金结算后，本次访问结束，不能在同一次停留中反复入场。
- 经过赌场而不停留，不获得入场资格。

### 3.3 与回合流程的关系

```text
停在星港赌场
→ 阶段进入 manage
→ 地块弹窗出现「进入赌场」
→ 玩家可选择进入或直接结束回合
→ 入场后完成一次赌场会话
→ 结算离场
→ 回到 manage，可结束回合
```

## 4. 核心玩法：牛熊轮盘

### 4.1 基本流程

1. 玩家入场，选择初始筹码。
2. 初始筹码从现金中扣除，进入“场内筹码”状态。
3. 第一次转动前不可直接落袋，必须先转一次。
4. 每次转动结果：
   - **爆仓**：本轮筹码归零，会话结束。
   - **安全结果**：当前筹码按结果上涨，玩家选择「落袋」或「再转一次」。
5. 玩家落袋：场内筹码按当前金额转回现金。
6. 达到最大转动次数或赔率上限：自动落袋并结束。
7. 爆仓后不能在同一停留中重新买入。

### 4.2 轮盘结构

轮盘共 20 格：

| 结果 | 格数 | 对当前筹码的影响 | 颜色 |
| --- | ---: | --- | --- |
| 崩盘 | 5 | 归零，本轮结束 | 黑 / 暗红 |
| 微涨 | 6 | ×1.10 | 墨绿 |
| 上涨 | 4 | ×1.20 | 青铜 |
| 大涨 | 3 | ×1.40 | 金色 |
| 暴涨 | 2 | ×1.80 | 亮金 / 白 |

概率：

```text
爆仓概率 = 5 / 20 = 25%
安全概率 = 15 / 20 = 75%

安全结果平均倍率
= (6×1.10 + 4×1.20 + 3×1.40 + 2×1.80) / 15
= 1.28

单转期望倍率
= 0.75 × 1.28
= 0.96
```

因此每转的理论庄家优势为：

```text
1 - 0.96 = 4%
```

### 4.3 为什么这个玩法不容易稳定赚钱

- 每一转的期望倍率是 `0.96`，低于 1。
- 当前筹码在每次转动时全部承担爆仓风险。
- 继续转动不是“锁定收益”，而是把已有筹码重新投入一个负期望事件。
- 玩家可以在任意安全结果后落袋，但这只是停止继续亏损的期望，不会把整体期望变成正数。
- 最大 10 转和 10 倍赔率上限会截断极端幸运收益。
- 任何“见好就收”或“追到 2 倍”的固定策略，长期期望都不会超过本金。

理论上，如果把当前筹码看作一个乘性过程，安全时乘以大于 1 的随机倍率，爆仓时归零，而单转期望小于 1，那么这是一个上鞅过程。只要不引入额外补贴，任何停止策略的期望都不会超过初始筹码。

> 注意：这不等于“每个玩家每次都会输”。单次仍可能赢，甚至可能连续上涨；但长期重复参与无法形成稳定盈利。

### 4.4 刺激点设计

- **可感知的筹码增长**：每次安全结果，筹码数字滚动上涨。
- **落袋与继续的对抗**：按钮顺序和视觉层级把“落袋”设为主按钮，把“再转”设为风险按钮。
- **爆仓反馈**：轮盘停在黑色格，红光、筹码散落、短促低音，不播庆祝音效。
- **大奖反馈**：亮金格出现金色光晕和筹码喷发，但赔率有上限。
- **无自动连转**：每次继续都必须重新点击，避免玩家在无意识状态下连续输钱。

### 4.5 建议的名字和视觉主题

- 赌场：**星港赌场**
- 轮盘：**牛熊轮盘**
- 宣传短句仅用于场内装饰，不进入主界面引导：`THE HOUSE ALWAYS HAS AN EDGE`
- 轮盘中心：星港徽章
- 主色：深墨绿、黑漆、黄铜、暗红、暖金
- 风格：海湾 Art Deco 娱乐场，而不是廉价霓虹赌厅

## 5. 下注、赔率与硬限制

### 5.1 筹码规则

- 1 万现金 = 1 万筹码，无兑换手续费。
- 入场时从现金扣除筹码。
- 场内筹码不可用于股票、地产、交易、还贷或支付租金。
- 离场时按当前筹码结算回现金。
- 爆仓时筹码归零。
- 赌场内不提供贷款、取存款、抵押地产或出售股票的追加筹码入口；这些操作必须离场后才能进行。
- 入场前已有的现金可以使用；但入场后不能因为输钱从其他资产中途补筹码。
- 不允许把筹码转给其他玩家。

### 5.2 下注范围

建议配置：

```text
最小筹码：10 万
最大筹码：200 万
单次停留：最多 1 次入场
单次会话：最多 10 转
单注赔率上限：10 倍
```

最大筹码还要满足保护线：

```text
保留金 = max(30 万, 下回合预计固定支出 × 2)
可下注现金 = 现金 - 保留金
最大筹码 = min(200, floor(可下注现金 × 25% / 10) × 10)
```

规则：

- 现金为负时禁止入场。
- 计算后最大筹码低于 10 万时禁止入场。
- 保留金必须留在现金中，不能全部押上。
- 不提供“全押”快捷按钮。
- 不允许在拍卖期间进入赌场。

### 5.3 会话上限

- 每次会话最多 10 转。
- 当前筹码达到初始筹码的 10 倍时自动落袋。
- 10 转后仍未爆仓或落袋，自动按当前筹码结算。
- 结算后本次访问结束，不能在同一回合重新入场。
- 不允许通过刷新页面重开一次会话；会话由服务端保存，刷新后恢复。

### 5.4 经济影响

- 赌场是现金回收池，长期从玩家群体中回收现金。
- 单次大奖会创造现金，但受 10 倍上限和 200 万最大筹码限制，最高单局结算为 2000 万。
- 2000 万属于极端事件，但仍是很大的现金注入，需要在平衡模拟中单独观察。
- 如果大奖出现频率导致地产/股票价格失控，可优先降低最大筹码或把赔率上限降到 8 倍，而不是暗改概率。
- 首版不额外征收赌场税；庄家优势已经包含在轮盘赔率中。若仍需要加强现金回收，应调整公开的赔率或筹码上限，不做隐藏抽水。
- 赌场不产生被动收入，不进入地产租金和股票估值体系。

## 6. 会话、断线与回合约束

### 6.1 服务端会话状态

建议在玩家状态上增加可选会话：

```ts
interface CasinoSession {
  stake: number;
  pot: number;
  spins: number;
  lastSector: number | null;
}

interface Player {
  casinoEligible?: boolean; // 本回合停在赌场，尚未使用入场资格
  casino?: CasinoSession;    // 正在进行的一次赌场会话
}
```

说明：

- `stake` 是初始筹码，用于计算 10 倍上限。
- `pot` 是当前场内筹码。
- `spins` 是已转次数。
- `lastSector` 用于前端还原轮盘最终停留位置。
- `casinoEligible` 在停在赌场时设为 true；入场后消耗；结束回合时清除。

### 6.2 回合约束

赌场会话进行中：

- 禁止结束回合。
- 禁止股票、银行、地产、交易等其他操作。
- 允许的操作只有：转动、落袋、离场。
- 玩家离开赌场或现金结算后，才恢复普通操作。

如果玩家在会话中点击结束回合，服务端应拒绝，并提示“请先离开赌场”。前端应直接禁用结束回合按钮，避免玩家反复碰壁。

### 6.3 断线与刷新

- 每次转动都是服务端原子结算，不存在“轮盘还在转、结果未定”的中间态。
- **短暂断线/刷新**：会话保留 30–60 秒重连宽限期；玩家重新连接后恢复筹码、次数和界面。刷新不应立即清空已赢筹码。
- **主动离开房间或宽限期超时**：
  - 如果有会话，自动按当前筹码落袋回现金；
  - 记录日志；
  - 清除会话和入场资格。
- 服务端崩溃重启时，存档加载阶段应扫描未结算的赌场会话，自动落袋，避免筹码卡死。
- 自动落袋只发生在会话空闲时，不会替玩家决定继续或下注。
- 重连宽限期内，其他玩家会看到该玩家尚未结束回合；超时结算后才允许继续流转，具体超时值应在实现时配置。

> 为什么允许自动落袋：爆仓只会在点击转动后由服务端结算，空闲时筹码没有风险；自动落袋只是把已赢到的筹码放回现金，不是替玩家做新的赌博决定。

### 6.4 现金与净资产

- 入场时现金扣除，筹码单独保存在 `casino.pot`。
- 场内筹码显示为“场内筹码”，不参与股票、银行、交易、还贷和租金。
- 无论输赢，必须在结束回合前完成结算，因此不会跨回合避税、避债或刷信用。
- 赌场界面同时显示：
  - 可用现金
  - 场内筹码
  - 若立即落袋的总现金
- 对局结算和排名使用最终现金，不直接使用场内筹码。

## 7. 游戏 UI

### 7.1 入场入口

玩家停在赌场后，地块弹窗显示：

```text
星港赌场
海湾文旅 · 特殊地块
场内规则：现金入场，庄家优势约 4%/转
最大筹码 200 万 · 最多 10 转

[进入赌场]   [离开]
```

设计原则：

- **不把“进入赌场”做成底部主 CTA**。主 CTA 仍然是回合推进；赌场是可选支线。
- 地块弹窗里提供入口，避免赌博被包装成必经流程。
- 现金不足、非当前玩家、拍卖期间时按钮禁用并说明原因。

### 7.2 赌场主界面

建议使用一张独立的深色 Art Deco 卡片或全屏遮罩，地图置后并降低亮度。

布局：

```text
┌──────────────────────────────────────────────┐
│ 星港赌场                      [规则] [静音] X │
├──────────────────────┬───────────────────────┤
│                      │ 可用现金     200 万    │
│      20 格轮盘        │ 场内筹码      40 万    │
│      金色指针         │ 已转次数       2 / 10  │
│      中心徽章         │ 当前倍率      1.44×   │
│                      │ 单局上限      10×     │
│                      │                       │
│                      │ [落袋 57.6 万]        │
│                      │ [再转一次]             │
├──────────────────────┴───────────────────────┤
│ 本轮结果：上涨 +20% · 爆仓概率 25%/转         │
└──────────────────────────────────────────────┘
```

按钮层级：

| 状态 | 主按钮 | 次按钮 |
| --- | --- | --- |
| 尚未开始 | 入座并转动 | 离开 |
| 安全结果 | 落袋 X 万 | 再转一次 |
| 爆仓 | 离开 | 无 |
| 达到上限 | 结算并离开 | 无 |

重要：**安全结果出现后，主按钮永远是“落袋”，继续转动永远不是主按钮。** 这不是替玩家做决定，而是避免把高风险动作做成默认动作。

### 7.3 轮盘动画

- 轮盘为 20 格，颜色按结果类型区分。
- 指针在正上方。
- 点击转动后，服务端立即结算，前端播放约 3–4 秒的旋转动画，最终停在服务端结果对应的格子。
- 转动过程显示“市场情绪”文案，但不显示确定的下一步结果。
- 爆仓时轮盘停稳后进入短暂暗场，筹码散落，显示“爆仓”。
- 安全时筹码数字滚动，显示当前倍率。
- 不做“差一格中奖”的额外放大或慢动作；结果由服务端确定。

### 7.4 移动端

- 轮盘在上，控制区在下。
- 筹码、现金和次数保持一屏可见。
- 主按钮高度不低于 44px。
- 不使用横向滚动。
- 390px 和 320px 宽度下不溢出。
- 系统开启减少动态效果时，轮盘改为淡入并直接显示结果，但仍保留结果和按钮。

### 7.5 声音

声音为可选增强，不阻塞玩法：

- 转动 tick 声
- 安全结果的筹码声
- 爆仓低音
- 大奖短促铜管/金币声

实现要求：

- 必须由用户手势触发，不能自动播放。
- 有独立静音开关。
- 不依赖“减少动态效果”设置来决定是否静音。
- 没有授权音源时宁可不做，不引入来源不明的音频。

## 8. 星港赌场建筑

### 8.1 建筑定位

“星港赌场”要成为海湾文旅区最容易认出的建筑，但不能压过中央银行和中央广场。

建议：

- 3 层主体 + 屋顶塔楼/穹顶
- 屋顶带一个慢速旋转的轮盘标志
- 总高度约为普通 Lv.3 地产的 1.4–1.6 倍
- 占地保持在原 19 号地块安全边界内
- 主立面朝向环形道路
- 模型查看页也纳入城市典藏

### 8.2 外观细节

- 深墨绿或黑漆立面，黄铜竖向线条
- 两翼对称，中央拱形门廊
- 金色雨棚和红毯，入口两侧黄铜立柱与天鹅绒围栏
- 暖金色玻璃门厅，内部可见吊灯剪影
- 屋顶中央的发光轮盘标志，20 个灯格缓慢明暗变化
- 侧翼竖排霓虹字牌 `STARPORT`
- 檐口灯泡跑马灯，但速度要慢
- 门前喷泉、棕榈盆栽、代客泊车台
- 夜间自发光材质和柔和光晕，不依赖昂贵后处理

### 8.3 性能与规范

- 灯泡、栏杆、装饰柱使用实例化网格。
- 不使用大面积透明叠层。
- 轮盘旋转、灯泡、喷泉只更新矩阵/颜色，不逐帧触发 React 状态。
- 减少动态效果时，轮盘和跑马灯停止，保留静态灯光。
- 建筑外轮廓、支撑结构、屋顶和招牌必须通过现有几何测试。
- 不超出地块边界，不遮挡相邻地块标签。

### 8.4 与地图/镜头的关系

- 游戏内保留地名标签，停在赌场时镜头聚焦该建筑。
- 登录展示城市的自动环绕中，赌场作为地标出现，但不显示地名。
- 进入赌场界面时，3D 地图后退并降亮，轮盘 UI 成为焦点。
- 从赌场退出后，视角回到原棋盘，不重置玩家位置。

## 9. 服务端规则

### 9.1 动作

建议新增：

```ts
{ type: 'casinoEnter'; stake: number }
{ type: 'casinoSpin' }
{ type: 'casinoCashout' }
```

可选：

```ts
{ type: 'casinoLeave' } // 与 cashout 合并也可以
```

服务端校验：

- 对局进行中。
- 当前玩家。
- 停在赌场地块。
- 管理阶段。
- 无拍卖。
- 现金非负。
- `casinoEligible` 为 true。
- 筹码在合法范围。
- 尚未存在活动会话。

### 9.2 结算流程

```text
casinoEnter:
  扣现金
  创建 session(stake, pot=stake, spins=0)
  casinoEligible=false
  记录日志

casinoSpin:
  校验 session
  服务端抽 0..19
  爆仓 → pot=0，清 session，记录结果
  安全 → pot *= 倍率，spins++
  达到 10 转或 10 倍 → 自动 cashout
  返回结果 sector

casinoCashout:
  现金 += pot
  清 session
  记录日志
```

### 9.3 随机数

- 使用服务端 `crypto.randomInt(0, 20)`，不使用客户端传入的结果。
- 每转独立，不根据玩家余额、之前输赢或下注大小改变概率。
- 轮盘格顺序固定，概率公开。
- 可额外保存最近结果用于审计，但不能用于动态调概率。
- 测试中注入固定随机源，避免概率测试抖动。

### 9.4 失败与回滚

- 所有校验必须在扣款和改状态之前完成。
- 非法请求不产生部分状态。
- 转动失败不消耗次数，不改变筹码。
- 现金不足、会话不存在、重复结算都应返回明确错误。
- 断线自动落袋也必须走服务端结算，并记录日志。

## 10. 经济平衡与测试

### 10.1 数学验收

- 20 格分布固定。
- 单转期望倍率 = `0.96`。
- 模拟 100 万次单转，实际平均倍率在容差内接近 `0.96`。
- 模拟“永远继续直到爆仓/上限”“1.2 倍落袋”“2 倍落袋”“随机落袋”等策略，长期平均收益全部低于本金。
- 最大 10 倍上限生效。
- 最大筹码和保留金规则不能被绕过。
- 不允许通过刷新页面重置次数、筹码或随机结果。

### 10.2 功能验收

- [x] 停在赌场后出现可选的“进入赌场”，不强制。
- [x] 现金不足、非当前玩家、拍卖期间无法进入。
- [x] 入座扣现金，场内筹码正确显示。
- [x] 爆仓后筹码归零，不能在同一停留中重新买入。
- [x] 安全后可以落袋，金额正确转回现金。
- [x] 继续转动必须再次点击，不存在自动连转。
- [x] 达到 10 转或 10 倍自动结算。
- [x] 短时间刷新后会话能恢复，超时断线会自动落袋且不会卡死。
- [x] 赌场会话期间不能结束回合或使用其他资产操作。
- [x] 赌场结果不影响股票、地产价格或租金。
- [x] 移动端、键盘和减少动态模式可用。

### 10.3 建筑验收

- [x] 19 号地块正确显示星港赌场。
- [x] 建筑不越界，不遮挡相邻地块。
- [x] 招牌、雨棚、入口、屋顶轮盘结构有支撑。
- [x] 模型三角面数在预算内。
- [x] 城市典藏页可查看。
- [x] 登录展示城市的自动环绕中可看到赌场，但不显示地名。
- [x] 减少动态效果下旋转和灯光动画停止。

### 10.4 平衡观测

上线前跑完整对局模拟，记录：

- 玩家进入赌场的比例
- 平均下注额
- 平均会话转数
- 爆仓率
- 落袋收益分布
- 单局最高结算
- 赌场前后净资产变化
- 是否出现“靠赌场快速超过地产/股票收益”的情况

如果赌场成为最优策略，优先调整：

1. 降低最大筹码
2. 降低赔率上限
3. 提高庄家优势
4. 减少会话次数

不要用隐藏的动态赔率或针对赢家调概率。

## 13. 风险与开放问题

### 13.1 风险

| 风险 | 处理 |
| --- | --- |
| 赌场成为最快赚钱方式 | 负期望、筹码上限、10 倍赔率上限、每回合一次 |
| 玩家用贷款/抵押继续赌 | 禁止非现金筹码和场外融资 |
| 刷新重开或卡住筹码 | 服务端会话、自动落袋、存档迁移 |
| 爆仓动画让人误以为可以操作 | 结果出来前禁用按钮 |
| 轮盘概率被怀疑作弊 | 固定 20 格、公开概率、服务端 crypto 随机 |
| 建筑过大遮挡棋盘 | 占地不越界，高度受控，几何测试 |
| 移动端性能 | 实例化、低透明、减少动态模式 |

### 13.2 需要确认

1. 是否同意把 19 号「市场消息」替换为赌场？
2. 赌场名字是否采用“星港赌场”，轮盘是否采用“牛熊轮盘”？
3. 庄家优势 4% 是否足够，还是首发就设 5%–6%？
4. 是否允许 AI 进入赌场？
   - 建议不做：AI 赌博会让平衡和测试方差变大。
5. 是否要公开播报大额赢钱？
   - 建议不做，避免鼓励其他玩家追赌；可以只在个人日志中显示。
6. 断线时自动落袋是否接受？
   - 建议接受，避免筹码卡死。
7. 赌场是否只允许落在该格时进入？
   - 建议是，避免变成随时可用的现金提款机。
8. 首版是否只做牛熊轮盘？
   - 建议是。先把一个玩法做完整，再考虑红黑轮盘、骰宝等小游戏。

## 15. 一页结论

- **建筑**：星港赌场，海湾文旅 19 号地块，Art Deco 三层 + 屋顶轮盘招牌，夜间灯光地标。
- **玩法**：牛熊轮盘，20 格，25% 爆仓，安全结果使筹码上涨；每次可选择落袋或继续。
- **为什么不容易赚**：单转期望 0.96，庄家优势 4%；继续转动会把全部筹码重新投入负期望事件，长期没有稳定策略。
- **限制**：现金入场，10 万–200 万筹码，最多 10 转，10 倍上限，每次停留一次入场。
- **安全边界**：赌场内不得借贷、取存款、抵押地产或用股票换取筹码；断线超时自动落袋；会话不跨回合。
- **第一版**：只做一个核心玩法，把建筑、规则、UI、测试做完整，不铺开成赌场小游戏集合。
