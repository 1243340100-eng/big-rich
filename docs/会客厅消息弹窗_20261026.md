# 会客厅消息弹窗

- 新消息在主界面右上方显示，包含发送者、全体/私聊标记和内容预览。
- 每条自动展示 5 秒，连续消息按顺序排队，后续消息不会覆盖或延长正在展示的一条。
- 自己发送的消息也会展示；聊天窗口打开时暂存，关闭窗口回到主界面后开始展示。
- 点击消息打开城市会客厅，也可以点击关闭按钮提前收起当前一条。
- 首次进入、刷新和切换房间不会重放已有的历史消息。私聊只对发送者和接收者提示。
- 弹窗不遮挡底部回合操作，长内容可点击进入会客厅阅读。

验证：生产构建通过；新增消息识别和隐私筛选测试通过；三名玩家的真实 Socket.IO 连接验证了消息发送、排队、私聊、点击打开、关闭及刷新场景。浏览器记录的两条连续消息展示时长约为 5011ms 和 5004ms，390px/320px 手机尺寸和桌面截图已保存。
