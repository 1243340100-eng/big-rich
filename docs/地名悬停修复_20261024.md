# 地名悬停稳定性修复

- 移除 LandmarkTag 的 JSX scale 属性，标签尺寸只由 BuildingLabels 控制。
- 可见标签使用自定义射线检测：隐藏自身或隐藏祖先的标签不再接收事件。
- 鼠标命中顺序与覆盖层显示顺序一致，避免牌子后面的建筑抢占悬停。
- Pointer-out 根据当前命中地块更新状态，避免旧对象的退出事件清除新悬停。
- 自动布局始终预留 104 像素宽的高亮空间，普通牌显示 84 像素，避免悬停放大触发裁剪或覆盖判定变化。
- Canvas 的 data-hovered-tile / data-label-layout 供悬停及显示尺寸验收使用。

验证：npm test 30 项通过，npm run build 通过；共享三维包仍有原有体积提示。

浏览器在首页进行独立检查，未创建房间或操作原有对局：

1. 未选中状态下，在银杏公寓牌子边缘悬停，hoveredTile=3，宽度持续 104 像素，坐标保持不变。
2. 移出后 hoveredTile 为空，宽度恢复 84 像素。
3. 切换湖畔住宅后 hoveredTile=5，新牌宽度持续 104 像素，旧牌恢复 84 像素。
4. 最终检查未捕获浏览器 warning/error。
