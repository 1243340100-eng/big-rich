# 对局结算胜利动画

## 1. 触发时机

仅当房间状态从 `playing` 变为 `finished` 时触发：

- 完成设定轮数后，服务端写入 `status: 'finished'` 和 `finishedAt`。
- 客户端 `useVictory` 检测到状态迁移，打开结算动画。
- 刷新/重连/重新进入已结束房间不会重播动画，但右侧仍显示最终排名。
- 新开一局或切换房间会清除旧的结算动画。

## 2. 动画内容

- 全屏暗场 + 模糊，中央深绿金边结算卡。
- 金色奖杯弹入、冠军姓名、最终净资产大号数字。
- 56 片彩带与金币从顶部飘落，按对局 id 稳定播种。
- 完整最终净资产排名，冠军行带奖杯。
- “你赢得了这座城”仅在本人夺冠时显示；否则显示“对局结束”和冠军名。
- 开启“减少动态效果”时不显示彩带/金币，卡片直接出现。
- 可点击右上角 ×、遮罩或“查看棋盘”关闭；点击“返回首页”会关闭动画并打开离房确认。

## 3. 音效

- 新增 `victory` 号角音：C5–E5–G5–C6–E6–G6 上行。
- 只在动画首次挂载时播放一次；受“启用游戏音效”控制（默认静音）。
- 与结算金币音效区分，避免同时播放。

## 4. 城市典藏预览入口

`models.html` 侧栏“效果预览”新增“播放胜利动画”按钮：

- 使用固定的 4 人样例排名：城市投资人 831.0 万、林 · 稳健派 682.3 万、周 · 增长派 519.2 万、陈 · 地产派 386.5 万。
- 预览“本人夺冠”的完整动画、彩带/金币雨和最终排名。
- 不连接房间、不写入存档；关闭后回到模型页。

## 5. 代码位置

- 胜利检测、彩带和排名组件：`src/game/VictoryOverlay.tsx`
- 动画样式：`src/game/victory.css`
- 音效：`src/game/feedback.tsx` 的 `victory` cue
- 接入：`src/App.tsx` 的 `useVictory` / `VictoryOverlay`
- 排名口径：`netWorth`（现金 + 存款 + 房产市值 + 股票市值 − 全部债务）

## 6. 测试

`tests/victory.test.ts` 覆盖：

- 最终排名按净资产降序且冠军稳定。
- 冠军本人看到“你赢得了这座城”、净资产、完整排名和 56 片彩带。
- 非冠军看到“对局结束”和冠军名。
- 减少动态效果时不渲染彩带。

全量 `npm test` 与 `npm run build` 通过后部署。
