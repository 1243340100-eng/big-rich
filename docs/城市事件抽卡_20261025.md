# 城市事件抽卡（2 / 16 / 27）

## 1. 目标

- 三个城市事件格不再共用“±8～18 万”的四个老结果。
- 每个格子有独立主题和 6 条事件，覆盖现金、按持有地产结算、全城发放和股市消息。
- 落点时播放抽卡翻牌动画；结果由服务端结算，动画只负责展示。

## 2. 事件池

稀有度权重：**普通 60% / 少见 30% / 稀有 10%**，每池 2 普通 + 2 少见 + 2 稀有。

## 3. 抽卡动画

- 落在 2 / 16 / 27 时，服务端先结算，再把结构化结果写入日志的 `cityEvent` 字段。
- 客户端检测到新的 `cityEvent`：
  - 普通事件只对落点玩家展示；
  - `global` 城市事件（建城纪念日）对所有玩家展示。
- 动画流程：卡背 → 450ms 后 3D 翻牌 → 卡面显示稀有度、地块、标题、描述、结果。
- 卡面可点击翻牌、按钮/遮罩/Esc 关闭；7 秒后自动关闭。
- 开启“减少动态效果”时直接显示正面，不翻转。
- 刷新、重连、切换房间不会重播旧卡。

## 4. 城市典藏预览入口

`models.html` 侧栏新增“效果预览”：

- 抽卡样例下拉：普通、少见、稀有、全城、负面、股市消息 6 种样例。
- “播放抽卡动画”按钮：重播完整的卡背 → 3D 翻牌 → 卡面流程。
- 横幅样例下拉：金融危机、AI 技术革命、央行降息、经济繁荣。
- “播放事件横幅”按钮：预览顶部全球事件横幅。
- “播放胜利动画”按钮：预览冠军结算动画、彩带/金币雨和最终排名。

预览会临时覆盖模型页的 `economy` 显示，不连接房间、不写入存档。

## 5. 技术结构

- `shared/cityEvents.ts`：事件数据、稀有度权重、`pickCityEvent` 加权抽取。
- `server/cityEvents.ts`：`resolveCityEvent` / `drawCityEvent`，负责现金、税务、全城和股价结算。
- `server/engine.ts`：`land` 的 `event` 分支调用 `drawCityEvent`；`dispatch` 增加 `cityRandom` 注入，便于测试。
- `src/game/CityEventDraw.tsx`：抽卡组件与 `useCityEventDraw` 检测。
- `src/game/city-event-draw.css`：卡背、3D 翻牌、稀有度配色和响应式。
- `shared/types.ts`：`CityEventResult`、`Log.cityEvent`、`StockEvent.kind:'city'`。
