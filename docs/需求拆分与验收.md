# GDD 需求拆分与验收

依据：原始 GDD v0.1；原文保留。开发范围按第 78 节第一版 MVP；第 79、80 节作为明确的后续工作，不将远期设想冒充本次完成。

## 发布目标

第一版名称：资本之城 / Capital City。交付可本地启动、可以真实多人连接的 3D 经济桌游，不只是 UI 演示。优先验证规则闭环和服务器权威，再逐步引入更复杂的金融关系。

## 补充交付

- 2–8 人房间、6 位房间码、房主规则设置、3 位机器人练习局。
- 六种职业。企业家在 MVP 使用地产维护优惠，创业优惠待企业系统接入。
- 银行存款、每五轮股息、简化五阶段经济周期。
- 公共聊天、真人私聊、私人交易提案隔离。
- 刷新恢复身份、离线临时代管、服务器重启读取本地快照。
- 小屏滚动布局、游戏指南、资产出售 / 重组确认、连接与错误反馈。

## 当前不作出的承诺

没有公网正式发布；没有真实四设备联测、长时间压力测试或长期平衡验收。后续阶段没有放置无法操作的假按钮。当前财务数字均是虚拟游戏数值。
