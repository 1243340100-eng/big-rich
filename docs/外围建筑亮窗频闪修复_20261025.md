# 外围建筑亮窗频闪修复

已修复黄昏、深夜时外围建筑亮窗随微小镜头变化随机跳亮／跳灭的问题。

## 原因与改动

原着色器把逐像素插值的楼体位置输入 `fract(sin(...) * 43758.5453)`，再用阈值决定窗户亮灭。很小的插值舍入误差会被放大，使同一扇窗在相邻画面里得到不同结果。

`src/scene/cityMaterial.ts` 现在对楼体尺寸和位置使用 `flat` 插值限定，位置种子量化为整数，并按整数窗口编号做小范围模运算。每扇窗的亮灭由楼体和窗格固定决定，不依赖镜头。对分辨率不足的小窗提前平滑淡出，减少远景锯齿闪烁；同时更新材质程序缓存标识，避免继续复用旧着色器。

## 验证

- 独立 WebGL 对比夹具使用修改前材质复现问题；在黄昏、深夜及 10／40／160／400 距离分别采集 16 个仅有极小镜头位移的画面，并通过同机位“亮窗开／关”之差分离亮窗信号。
- 近景黄昏的亮窗平均帧差由 48.67 降至 0.048，深夜由 62.76 降至 0.056，受控测试波动降低约 99.9%。明显不稳定像素占比从约 76%–77% 降至约 0.016%；剩余单像素变化包含实际取景造成的边缘覆盖变化。
- 40 距离的明显不稳定亮窗像素为零；160 距离帧差为零；400 距离的过小亮窗按抗锯齿策略淡出。
- 完整场景检查覆盖三种时段、旋转、拉远、竖屏和棋盘交互，页面及控制台错误为零。
- `npm test`：117 项通过；`npm run build`：通过。生产文件已更新，刷新游戏页面即可加载。

GPU 夹具、原材质备份、截图、量化结果和日志位于 `artifacts/window-flicker-20261025/`。测试入口为 `check-window-flicker.cjs`，使用本项目的 Vite 服务（5173 端口）。
