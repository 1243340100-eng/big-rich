# 三级建筑与经济改动 · 施工验收

日期：2026-10-25。依据《三级建筑与经济改动清单_20261025.md》实施 P0、P1、P2。

## 已完成

- 银行回收按未抗跌估值的 70% 与估算投入的 85% 取较小值，再扣抵押债务；三级估值保护不会抬高银行回收价。
- 租金等级系数为 1 / 1.9 / 2.8 / 4.2。三级租金周期系数最低为 1，房产指数低于 1 时估值只承受一半跌幅，抵押率为 75%；其他等级仍为 60%。
- 同街区持有 2 / 3 / 4 / 5 块时，租金加成分别为 15% / 30% / 45% / 60%。
- 主动买入、拍卖、玩家交易统一计收反垄断税。受让人向银行付税，使用基础地价计税。现金不足会原子拒绝，接受交易时重新校验；拍卖预留同时包含报价和税款，交易改变持有数量时也会校验新的预留额。
- 首次三级封顶按关联板块当前三级建筑数量递减触发重估：基本面 15% / 8% / 4% / 2%，即时冲击 8% / 4% / 2% / 1%。31 号等双板块地块独立计算后合并冲击。
- 累计板块重估进入基本面，基本面上限为基础价的 2.2 倍。即时行情、图表事件、公开日志与累计重估展示已接入。
- 同一地块只触发一次。卖给银行、换人持有、重新建造、重连和服务重启都不会重置机会。
- 老存档新增空累计重估记录；已有三级地块标记为已使用，不追发重估，不改持仓成本、现金、原有行情。
- 地块简报显示街区加成、周期与三级保护；升级面板显示三级特权和关联公司；新增买入确认税款明细；拍卖和交易提前显示税费；出售确认说明 85% 封顶。
- AI 的买入、竞拍和交易判断计入反垄断税，并可在保持现金缓冲的前提下升级至三级。

## 已确认的执行口径

1. 即时冲击也由其余五个板块均摊，使用“冲击 ÷ 5”。每次轮动的百分比增量合计为零。
2. 保留固定冲击比例，不按持仓大小动态限额。10 股示例通过；不承诺任意大持仓的收益都小于升级费。
3. 31 号首次封顶同时联动能源与科技：各自得到 +15% 基本面，同时承受另一板块的 −3%，各自净增加 +12%；即时净冲击各 +6.4%。其余四板块基本面各 −6%、即时各 −3.2%。
4. 文档的简化例子：20 万基础价 × 15% × 10 股 = 30 万，小于云端总部标准单次升级费 71.55 万。按实际双板块即时结算，10 股科技股增值为 12.8 万；单联动的创意工坊为 16 万，小于其升级费 36.45 万。
5. 银行成本上限沿用文档的“当前指数地价 + 标准升级费”估算公式，不新增历史买入成本账本。
