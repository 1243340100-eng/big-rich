# 可升级地产 Level 3 豪华造型（首批样板·第三版）

- 日期：2026-10-24
- 状态：首批三栋已重做为独立 Lv.3 豪华模型；本轮重做云端总部并美化海湾酒店
- 范围：只替换 15、18、31 三栋地产的 Lv.3 外观；Lv.0–Lv.2 保持原样
- 不改变：升级费用、租金、维护、占地、地块归属和任何服务端规则

## 1. 这次不是叠加装饰，而是整栋重做

第一版是在原建筑上增加屋顶构件，轮廓变化不够明显。第二版直接把这三栋的 Lv.3 模型替换为新的豪华建筑：

| 地块 | 原 Lv.3 轮廓 | 新 Lv.3 参考方向 | 新高度 |
| --- | --- | --- | ---: |
| 15 天际中心 | 三级收分塔楼 + 细尖顶 | 装饰艺术摩天楼、Chrysler 式层叠金冠 | 2.30 |
| 18 海湾酒店 | 双翼客房 + 屋顶 H 招牌 | 帆船酒店式弧形玻璃帆、曲线楼层、金色桅杆与空中餐厅 | 2.18 |
| 31 云端总部 | 高低双圆塔 + 连桥 | 街色谱系收分塔楼、双层悬挑云板、发光云冠与塔尖 | 2.35 |

参考的是建筑语言，不是照搬现实建筑的完整外形。

## 2. 天际中心：装饰艺术金冠塔

Lv.3 变成一座明显更高的退台塔楼：

- 三层收分塔身与连续黄铜檐口。
- 竖向金色壁柱和暖光窗带，形成装饰艺术立面。
- 顶部换成八面金冠：
  - 两级八角灯笼式冠部
  - 环形灯带与八条放射金肋
  - 观景平台、金色栏杆
  - 细长针尖与顶部信标
- 入口增加柱廊、雨棚和发光门厅。
- 修正穿模：移除原本悬在塔身两侧的灯饰，改成落在退台面上的角部尖塔；补充侧立面窗、裙房侧窗和转角铜鳍，避免大面积空白侧墙。

![天际中心 Lv.3](../artifacts/prestige-level3-review-20261024/skyline-hero-v3.png)

## 3. 海湾酒店：帆船式海景酒店

Lv.3 从横向双翼酒店改成一整面弧形玻璃帆：

- 完整的弧形玻璃帆船幕墙，冷色玻璃与暖色室内窗带。
- **十二道楼层板沿帆面曲线逐层收窄**：按两条二次贝塞尔曲线采样出前缘高度对应的宽度，楼板与暖光灯带一起跟随收分，帆面不再是一整片空白玻璃。
- 楼层收边绕过帆面弧线，从侧面看也有连续的层线。
- 竖向金色幕墙肋，取消原先向外悬出的水平浮条。
- 空中餐厅平台、空中大堂都加了斜撑支架、侧玻璃和金色顶棚。
- 顶部不再用悬空的半圆弧，改成**随屋面倾斜的金色冠带**：屋面盖板、前后檐口与檐口灯带都按帆面顶边的 4.4° 倾角摆放，因此冠部必然贴合轮廓、不会出现弧线两端悬空的问题。
- 金色桅杆原先是悬在帆面前的独立杆件，现在改成**贴着帆缘（x = -0.306）的金色脊**，从裙房起吊到 2.18，四级环箍 + 拉杆把它拉回立面，顶部留一个小半环作信标。
- 背面补齐：同一套楼层竖檩与暖窗延伸到屋顶，新增**后部设备核**（楼层带、竖向暖光槽、压顶与屋顶机组）和**后门厅雨棚**。
- 侧面补齐：帆缘一侧原本是一整片空白墙，现在加楼层收边与三排窗洞。
- 裙房加入**临海拱廊玻璃、转角壁柱与水景花池**，门厅改为发光玻璃幕墙，棕榈补上可见树干。

![海湾酒店 Lv.3](../artifacts/redo-review/hotel-lv3.png)

## 4. 云端总部：云板云冠塔（已重做）

Lv.3 在本轮被整体重做。旧方案的米色石材 + 金色晶塔与所在街区（未来产业，石绿墙面配青绿金属）格格不入，新方案改为**结构、收边、灯槽全部取自街区调色板**：

- 裙房：落客平台、石绿墙身、青绿压顶、发光门厅幕墙、柱廊雨棚、入门台阶与两侧花池。
- 塔身：一条连续的收分棱台（`taperedBox` 手写 8 顶点、36 索引几何），四角有随收分倾斜的金属棱鳍，立面为玻璃带 + 竖向挺杆 + 发光灯槽。
- **双层悬挑云板**：比塔身外挑的观景平台，带栏杆、角部植栽、底部发光灯槽和斜撑支架。
- **最宽的金冠平台**：宽度超过塔身，成为整栋最宽的一道悬挑平台，四角用斜撑托住，栏杆围合。
- 冠部：八角发光灯笼（四角立柱 + 四面发光玻璃 + 压顶），再接塔尖与信标。
- 高度仍为 2.35，与 Lv.2 的双圆塔剪影完全不同。

   - 花园住区：低层豪宅、庭院和玻璃温室

   - 海湾文旅：帆船、酒店塔和度假屋顶
   - 未来产业：空中花园、玻璃塔和科技冠部
